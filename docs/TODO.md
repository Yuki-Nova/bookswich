### P2 待修：HTML 表格内公式/标题不渲染（2026-08-17 用户反馈，已定位未修）

**现象**：vault 概率统计「本章内容提要」板块，表格内 `$...$` 公式 Obsidian 不渲染；
表格相邻的 `## 2. 二维连续型随机向量` 等标题也不渲染（显示为字面 `##`）。

**根因（字节级确认，文件 04_第四章 随机向量及其分布.md）**：
1. 内容提要表格是 **HTML `<table>`**（门禁未过：含 `rowspan="2"`、单元格长文本）——
   Obsidian 解析器不处理 HTML 标签内部的 inline math（与 OB-2 `<eq>` 结论同源，
   `$...$` 在 HTML 表格内同样不渲染）
2. `_node_to_md` 的 **HTML 保留路径输出无前后空行**：`format_html_table` 直接拼接，
   产生 `</table>\n## 2. ...\n<table>`——标题紧贴 HTML 块两侧无空行，Obsidian 不识别为标题
   （对比 MD 转换路径 `format_table_md` 自带 `\n` 包裹，无此问题）

**修复方向（待执行）**：
- [ ] A. `_node_to_md` HTML 保留路径输出加前后空行（`\n\n` 包裹）→ 解决 `##` 粘连
      （低风险，可立即做）
- [ ] B. HTML 表格内 `$...$` 渲染：需更大方案——门禁放宽让更多表转 MD（拆分长单元格/
      rowspan 降级？）/ HTML 表格内公式转 KaTeX 支持的写法 / 或接受现状（HTML 表格
      本就是格式优先的兜底路径）。b1 全书 173 张 HTML 保留表中含公式的占比需先统计
